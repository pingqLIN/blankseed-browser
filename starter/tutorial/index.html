AI 模型接入速查

OpenAI 相容 loopback

先啟動本機模型伺服器，再到 Agent 分頁的「AI 模型接入」區填入端點與模型 ID。端點僅接受 loopback（本機回環），且不會送出授權標頭。下列環境變數是啟動前的替代設定方式。

$env:BLANKSEED_LOCAL_MODEL_ENDPOINT = 'http://127.0.0.1:1234/v1/chat/completions'
$env:BLANKSEED_LOCAL_MODEL_NAME = 'local-model'
try { npm start } finally {
  Remove-Item Env:BLANKSEED_LOCAL_MODEL_ENDPOINT -ErrorAction SilentlyContinue
  Remove-Item Env:BLANKSEED_LOCAL_MODEL_NAME -ErrorAction SilentlyContinue
}

OpenAI Responses API

正式程式可在 Agent 分頁輸入暫時 OpenAI API 金鑰。金鑰送到 Main Process（主程序）後會立即清空輸入框，只保留於本次程式記憶體；generated Node（產生的 Node 程序）、模組測試與模組呼叫都不會繼承金鑰。教學頁不接受真實金鑰。下列環境變數仍可作為啟動前的替代方式。

$blankseedKey = Read-Host 'OPENAI_API_KEY' -AsSecureString
$env:OPENAI_API_KEY = [Net.NetworkCredential]::new('', $blankseedKey).Password
try { npm start } finally {
  Remove-Item Env:OPENAI_API_KEY -ErrorAction SilentlyContinue
}
